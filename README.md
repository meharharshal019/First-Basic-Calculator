# 🧮 Smart Calculator

A modern calculator web application built using **Python, Flask, HTML, CSS, and JavaScript**.

## 🚀 Features

* Basic arithmetic operations

  * Addition (+)
  * Subtraction (-)
  * Multiplication (×)
  * Division (÷)
  * Percentage (%)

* Modern user interface

* Responsive design

* Live date and time display

* Calculation history

* Dark theme design

* Smooth button animations

## 🛠 Technologies Used

* Python
* Flask
* HTML5
* CSS3
* JavaScript

## ▶️ How to Run

1. Install Flask

```bash
pip install flask
```

2. Open terminal in project folder

```bash
cd Calculator-App
```

3. Run application

```bash
python app.py
```

4. Open browser

```text
http://127.0.0.1:5000
```
